**核心是逐素数恒等式** `log(p/(p−1)) = 1/p − (log(1−1/p) + 1/p)`（两次 `Real.log_div` + `ring`），

### 🔴 学到的设计教训（重要，写进 record）

**「两个十进制常数」的拆法在数学上不可能**：倒数界只在 `c ≥ B₁` 时成立、尾部界只在 `d ≥ γ − B₁` 时成立，
而目标要 `c + d ≤ γ` ⇒ 逼出 `c + d = γ` ⇒ `c` 必须**恰好**等于 `B₁`（10 位精度）。
解法：两个孩子的陈述里都把 Mertens 常数**写成 `γ + ∑'_p(log(1−1/p) + 1/p)`**，
于是相减时**精确抵消**，全程**不需要 B₁ 的任何数值**。这是这个拆法能成立的关键。

### 23:00 对本节的**更正与细化**（上面那条「需要 ZFR/RH 型节点」的结论已作废）

   **和我们节点的常数写法完全一致**；而且**只含 ϑ，不需要 ψ**。
   文献引的 R–S Theorem 5 = `−1/(2log²x) < A₁(x) < 1/(2log²x)`（右侧 x ≥ 286）。
2. **要求比我说的小得多**：喂 `|ϑ(y)−y| ≤ c·y/log^k y` 进恒等式得
   `|A₁| ≤ c(1/(k log^k x) + 1/((k+1)log^{k+1}x))` ⇒
