```lean
theorem semi_magic_polynomial (n : ℕ) (hn : 1 ≤ n) :
    ∃ p : Polynomial ℚ,
      p.natDegree = (n - 1) ^ 2 ∧
        (∀ t : ℕ, p.eval (t : ℚ) = (semiMagicCount n t : ℚ)) ∧
          (∀ t : ℤ, p.eval (((-(n : ℤ) - t : ℤ) : ℚ))
```

- 🔴 **`Polynomial.eval₂` 不能用来写倒易律**：它要 `R →+* S` 且 `p : R[X]`，
  不存在 `ℚ →+* ℤ`；写 `eval₂ (Int.castRingHom ℚ) (-(n:ℤ) - t)` 会报类型不匹配
  （它坚持 `p : Polynomial ℤ`）。可行写法两条：(a) **先把整数打进 ℚ 再 `eval`**（采用），
  (b) 纯多项式恒等式 `p.comp (C (-(n:ℚ)) - X) = C ((-1:ℚ)^(n-1)) * p`（也验证可 elaborate）。
- 消失列表是 `1 ≤ k ≤ n-1` 上的 `p(-k)=0`；**n=2 就已经非空**（k=1），
  而 `H_2` 的 `X+1` 在 −1 处确实为 0（原型里证了），`H_3(-1)=H_3(-2)=0` 也在
  MacMahon 多项式上 `norm_num` 验证过。
- `semiMagicCount` **不用重定义**，`Finset.card` 直接可用。
- 设计书 `missions/magic-squares-v/DESIGN.md` §3 已回填这些结论（原「open questions」删掉）。
- 顺带踩坑：`Polynomial.natDegree_X_add_C` 只匹配 `X + C x` 字面形式，`X + 1` 里的
