### p²-1 | 24 的可行性实测

⚠️ **宇轩的写法方向反了**：`p²-1 | 24` 意思是「p²-1 整除 24」；他想说的应是 **`24 ∣ p²-1`**。

⚠️ **必须排除 p = 2, 3**：
- p=2：p²-1 = 3，3 ∤ 24 ✗
- p=3：p²-1 = 8，8 ∤ 24 ✗
- p ≥ 5：✓

**Mathlib 已有现成引理**：`Mathlib/NumberTheory/Multiplicity.lean:258,263`
`Int.eight_dvd_sq_sub_one_of_odd` / `Nat.eight_dvd_sq_sub_one_of_odd (hk : Odd k) : 8 ∣ k^2 - 1`。
即「8 | p²-1」在 Mathlib 里是**一行调用**，剩下只有 3 | p²-1。

**实测编译通过**（`tmp/probe_24.lean`，零错误零警告，约 20 行）：

```lean
example (p : ℕ) (hp : p.Prime) (h2 : p ≠ 2) (h3 : p ≠ 3) : 24 ∣ p ^ 2 - 1 := by
  have hodd : Odd p := hp.odd_of_ne_two h2
  have h8 : 8 ∣ p ^ 2 - 1 := Nat.eight_dvd_sq_sub_one_of_odd hodd
  have hyp : ¬ 3 ∣ p := by
    intro h
    exact h3 ((hp.dvd_iff_eq (by norm_num : (3:ℕ) ≠ 1)).mp h)
  have h3dvd : 3 ∣ p ^ 2 - 1 := by
    rw [← ZMod.natCast_eq_zero_iff (p ^ 2 - 1) 3]
    have hle : 1 ≤ p ^ 2 := by have := pow_pos hp.pos 2; omega
    have hcast : ((p ^ 2 - 1 : ℕ) : ZMod 3) = (p : ZMod 3) ^ 2 - 1 := by
      push_cast [Nat.cast_sub hle]; ring
    rw [hcast]
    have hpne : (p : ZMod 3) ≠ 0 := by simpa [ZMod.natCast_eq_zero_iff] using hyp
    have hsq : (p : ZMod 3) ^ 2 = 1 := by
      generalize hx : (p : ZMod 3) = x at hpne ⊢
      fin_cases x <;> first | exact absurd rfl hpne | decide
    rw [hsq]; ring
  exact Nat.lcm_dvd h8 h3dvd
```

**关键踩坑**（本次迭代出来的）：
- `Nat.Prime.dvd_iff_eq (hp : p.Prime) (a1 : a ≠ 1) : a ∣ p ↔ p = a` ——
  要证「3 ∣ p 且 p 素数 ⇒ p = 3」，得**以 hp 作主参**：`hp.dvd_iff_eq (by norm_num)`，
  写成 `Nat.prime_three.dvd_iff_eq ...` 方向会反。
- `fin_cases` **只能作用在变量上**，`fin_cases (p : ZMod 3)` 报 "Unexpected syntax"。
  先 `generalize hx : (p : ZMod 3) = x at hpne ⊢` 再 `fin_cases x`。
- ZMod 分支里 0 那支要靠 `hpne` 消，`simp_all` 单用不够 → 用
  `first | exact absurd rfl hpne | decide`。
- `ZMod.natCast_eq_zero_iff (a b : ℕ) : (a : ZMod b) = 0 ↔ b ∣ a` 是 ZMod ↔ 整除的桥。
- 需要 `Nat.cast_sub hle`（`1 ≤ p^2`）才能把 `↑(p^2 - 1)` 推进 ZMod，否则 ℕ 减法不映射。

### 结论（给宇轩的判断）

- 作为**公开 open problem** 提交：**不合适**。Mathlib 已有 8|p²-1 的现成引理，剩余 20 行，

- 更值得注意：宇轩 workspace 里已有 **weak-goldbach / five-primes / euler-gamma** 三个数论 mission
  （都是大问题归约路线），那才是他的优势位置。
