# 新研究 DAG 与 private mission 的对应范围

平台命题的 `Proved` 只覆盖其精确 Lean 陈述；本地数学 DAG 的节点范围可能更大。

| 本地节点 | 平台项 | 当前对应范围 |
|---|---|---|
| `Q` | `ZetaNine.volume_baseline_cancellation` | 仅在给定正量和面积等式 `Δ=s₁²NΞ/D²` 下证明对数消去；具体 `F_n,K_n,J_n,E_n` 的面积等式另列 Q1 里程碑。 |
| `X` | X 里程碑，暂未链接 Lean 定理 | 本地笔记证明真实变系数递推的二维外积谱上界；Lean 定义和证明仍待完成。 |
| `Y` | `ZetaNine.finite_prime_budget` | 仅证明有限非负权重的截断减法求和不等式；代入具体素数估值、`p>n` 项和素数定理仍在本地笔记。 |
| `YD` | `ZetaNine.finite_prime_discount` | 仅证明任意有限指标、自然数估值和实权重的精确截断减法恒等式；具体 ζ(9) 的素数替换、Smith 数据和渐近预算仍在本地笔记。 |
| `H` | H 里程碑，暂未链接 Lean 定理 | 本地笔记用有限域平移迹证明全部偶数 `n≥8`、素数 `p>n` 的 `v_p(N_n)≤⌊3n/(2p)⌋`；平台尚未验证。 |
| `Z` | Z 里程碑，暂未链接 Lean 定理 | 本地笔记证明 `p≤√(7n/2)` 的超额贡献为 `o(n)`；平台尚未验证。 |
| `I` | I 里程碑，暂未链接 Lean 定理 | 本地笔记证明中间素数合并极点迹引理及 `v_p(N_n)≤38`；它只是 VC 的粗输入，平台尚未验证。 |
| `LC` | LC 里程碑，暂未链接 Lean 定理 | 本地笔记给出不依赖 Smith 变换选择的内禀同余斜率公式；它不完成 S 的全方向排除。 |
| `TP` | TP 里程碑，暂未链接 Lean 定理 | 本地笔记证明正号短整数形式的严格非零性和部分同余格第一向量的精确提升指数 `B−σ`；具体 Taylor 锥尚未 Lean 定义。 |
| `TA` | TA 里程碑，暂未链接 Lean 定理 | 本地笔记证明实际两步 Taylor 连接最终严格保正、固定非零输出最终入锥；系数比值窗口按模 `4` 严格收缩且宽度指数率小于 `−10.1109`。 |
| `SP` | SP 里程碑，暂未链接 Lean 定理 | 本地笔记证明对任意预先规定且 `nh_n²/log n→∞` 的鞍点窗口，取样定号足以令完整无穷和非零；两个有限负和另有精确证书。 |
| `GC` | GC 里程碑，暂未链接 Lean 定理 | 真实正核的零至四阶高斯矩极限及锐常数窗；`A>√(3/a)` 保证移动四次多项式全和定号，`A<√(3/a)` 有一般四次反例，等号未决。 |
| `FQ` | FQ 里程碑，暂未链接 Lean 定理 | 五个预定实际整数采样点有最终全正的精确求积权重；每个非零移动四次多项式的五点弱同号保证完整无穷和严格非零。 |
| `GO` | GO 里程碑，暂未链接 Lean 定理 | 抽象整数二维多项式格的三点变号反例；证明几何上界单独不能推出 T5，绝非实际 `E_n` 的反例。 |
| `FI` | FI 里程碑，暂未链接 Lean 定理 | 五点有理比值窗严格夹住 ζ(9)，宽度指数率小于 `−10.1109`；T5 的弱同号等价于第一输出斜率避开开窗，端点允许。 |
| `FO` | FO 里程碑，暂未链接 Lean 定理 | 全部充分大偶数的每个第一输出统一逼近 ζ(9)，实值指数至少为 `δ−ε`；有理假设下第一方向最终锁成 primitive 零关系。这些笔记结论不证明 T5。 |
| `FC` | FC 里程碑，暂未链接 Lean 定理 | 真实五样本端点的伴随矩阵求值 gcd 精确给既约分母；整数间隔与外积高度界构成 `FD+FC⇒T5` 的逐参数桥梁。 |
| `FD` | FD 里程碑，暂未链接 Lean 定理 | 端点分母、窗宽和第一高度的乘积无穷次 `≤1` 仍开放；若成立则所有对应第一方向满足 T5 五点弱同号。 |
| `FM` | FM 里程碑，暂未链接 Lean 定理 | 有理替代连接保留同一极限谱、正求积与实际五个取样点，但使 T5 最终失败；不保留真实有限参数连接，不反驳实际 T5。 |
| `XL` | XL 里程碑，暂未链接 Lean 定理 | 真实逆像面积的下指数和第一输出高度上指数已在数学笔记中证明；第二模态尖锐下增长仍开放。 |
| `CM` | CM 里程碑，暂未链接 Lean 定理 | 高斯临界尺度上，`ζ(9)` 无理与 `λ₂,n Z_n→0` 等价，并与 `liminf λ₂,n Z_n=0` 等价；这是数学笔记的双向判据，不是开放方向的证明。 |
| `CP` | CP 里程碑，暂未链接 Lean 定理 | 真实格的 `liminf λ₂,n Z_n=0` 仍开放；由 CM 它足以证明根。 |
| `T5` | T5 里程碑，暂未链接 Lean 定理 | 实际完整输出格第一向量的无限次五点定号仍开放；与 FQ、X、A、F 合取足以推出根。 |
| `T`, `TS`, `TG`, `VD`, `V`, `VA`, `VB`, `VC`, `S`, `J` | 里程碑或 mission 说明（`V`、`VA` 暂无独立里程碑） | 数学上开放，平台不宣称已证；TS 只需某个固定 `A>0` 的 `A log n/√n` 鞍点局部符号。 |

平台 mission 说明写出双形式主线 `R←J,F,A,G,P`、`J←V,S`，临界备选 `R←CP,CM`，以及单形式备选 `R←T,TP,X,A,F`、`R←TS,SP,X,A,F`、`R←T5,FQ,X,A,F`、`R←TG,TP,V,A,F`；另有 `T5←FD,FC` 与算术线 `V←VA,Q,X`、`VA←VB,Y`、`VA←VD,YD,H,Z,Y`、`VB←VC,H,Z`。每组子节点需合取，同一父节点的多组归约是备选。I、LC、TA、GO、FI、FO、FM、XL 是研究输入。在具体序列完成忠实的 Lean 定义、并提交相应 proof-sketch 之前，平台的 theorem dependency graph 不会自动包含这些数学箭头。平台里程碑是研究目录，不是根定理的已验证形式依赖。40 个研究里程碑已完成 private 回读；根定理经回读为 `Open/private`。
