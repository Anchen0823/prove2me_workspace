# ζ(9) 第九轮：增长次数滤波的成本

本轮将第八轮的固定四次谱滤波障碍推广到次数随参数增长的情形。[完整证明](research/growing-filter.md)给出对 `Q∤P` 的整数多项式 `P` 的显式结式下界：

\[
|P(ρ)|\ge 22235661^{-d}\bigl((d+1)H(P)\,3709731751^d\bigr)^{-4}.
\]

因此，次数 `o(n)`、系数高度和分母均为 `exp(o(n))` 的滤波，无法在冻结极限矩阵的增长特征值上取得固定指数率的消去。若 `Q|P`，滤波在极限矩阵上是零算子；这一例外不能遗漏。第八轮关于次数至多四的论证是本结论的特例。

此结论进一步界定了原递推路线需要付出的次数或算术高度成本，但没有给出实际变系数递推的估计，也没有解决第七轮的同余格短向量下界。**ζ(9) 的无理性仍未证明。**
