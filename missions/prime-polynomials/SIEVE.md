# 目标长度47时的必要同余条件

设 P 属于 Z[x]，在 L 个连续整数处的 |P(x)| 都是两两不同的素数。
若素数 p 满足 2p ≤ L，则 P 在模 p 下不可能有根。

证明：假设 P(r)=0 mod p。连续 L≥2p 个整数中至少两项 x,y 同余于 r。
整数系数保证 P(x),P(y) 都被 p 整除。二者绝对值为素数，故均为 p，与互异矛盾。

所以 L≥47 时，模2,3,5,7,11,13,17,19,23无根是严格必要条件。
safe_search.cpp 只使用这些必要条件，保留所有可能达到47项的常数项，
随后逐项判断素性，并用滑动窗口排除重复。它不会因为 |P(x)| 恰好等于某个小素数而误删目标。

这只证明筛选对目标不漏解：系数仍随机抽样，输入仍限制在[-80,80]，
因此整个搜索不能声称穷尽所有多项式或证明纪录最优。

record_search.cpp 的筛选延伸至47，属于更激进的启发式；可能排除含±p例外的解。
两个版本按不同筛选条件分别记录，不能把统计混为一次完整穷举。

本轮模式：3=扩展三次；6=四次；safe版本的7=四次纪录附近局部搜索。
常数项范围[-498960,501269]，窗口[-80,80]。
编译产物放入tmp/prime-polynomial-build；结果放verification。

## 2026-09-24：保留例外的第二级筛选

对目标长度 L=47，素数 p=29,31,37,41,43,47：
如果 P 模 p 有根，每个 L 长窗口至少遇到一个被 p 整除的值。
要全部为素数，必须在扫描域内出现 P(x)=p 或 P(x)=-p。

写 P(x)=Q(x)+c，将扫描域内 Q(x) 的值排序。若 c 模 p 被禁，
用二分查找检查 p-c 或 -p-c 是否出现；两者都没有则严格排除候选。
出现仅代表必要条件成立，随后仍完整检查素性、连续性和互异性。
因此这一级筛选保留 ±p 例外，不会误删目标长度的候选。
使用整个扫描域而非每一个目标窗口来检查例外只会多留候选，不会漏解。

实现：scripts/exception_search.cpp；baseline 参数停用第二级以做相同候选集的基准。
tests/test 文件为 scripts/test_exception.cpp，覆盖150000个小范围测试，
其中20786个达到对应目标的正例全部保留，并单测4x²+7的p=7例外与五次49项实例。

本轮新增模式8：围绕3x⁵+7x⁴−340x³−122x²+3876x+997的形状，
对x⁴,x³,x²,x的一或两个系数作210的整数倍扰动，常数项仍完整轮筛扫描。
一次至多两个各在[-10,10]范围的扰动，同一系数可选两次；共2561种形状。
目标长度设50。最高筛选素数47依然适用。可选参数将扰动半径R扩至50，
此时形状数为1+16R+24R²=60801。素性试除表扩至200万，
这些受控系数/输入范围的输出小于2×10¹²，表不足时程序会报错而非声称素数。

第二级筛选只为指定目标保全候选，可能删除只有更短素数串的多项式，
因此它的较短最好长度不能当作搜索盒内所有较短纪录的最优值。
