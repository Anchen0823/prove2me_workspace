# 互异素数多项式搜索：2026-09-24

结论：本轮未打破目标纪录。二次重找到 45 项，三次重找到 46 项。
目标来自此前核对的 Dress–Landreau 历史纪录，不声称完成了截至今日的全球纪录审计。

## 口径

整数系数；连续整数输入；按绝对值判断素性；整段素数绝对值两两不同；1 不算素数。
扫描输入 [-80,80]。允许取绝对值是为了与历史纪录一致，不等同于始终输出正素数。

## 优化

- C++ 编译实现，5000 万以内查确定性素数位表，超出后用素数表精确试除。
- 对非恒定项固定的形状，预计算常数项模 2,3,5,...,43 的允许剩余类。
- 以 2310=2*3*5*7*11 为轮筛周期，只枚举允许的常数项。
- 滑动窗口处理重复值，扫描最长互异素数区间。
- v2 对非恒定系数组合去重；源码还在有限形状全部访问后提前结束。
- 独立 Python 验证器通过幂求和求值、精确试除验证所有改善记录。

重要限制：筛选要求模上述每个小素数均无根，会排除通过取值等于 ±p 避开合数的特殊候选。因此这是启发式破纪录搜索，不是整个系数盒的穷举最优证明。输入窗口也有限。

## 性能

同一组 10000 个多项式 36x²+18x+c（c=-5000..4999），各扫描161个输入。
单次测量 Python 0.7173 秒，C++ 0.01954 秒，约36.7倍；不含两端素数表初始化。
该比较只度量扫描实现，不代表完整搜索吞吐提升倍数。长度校验和相同，均为11632。
