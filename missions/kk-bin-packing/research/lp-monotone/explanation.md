# 配置 LP 的删除单调性与一般缩小情形的精确边界

本目录仅含独立研究源码，不导入任何平台开放定理。`LPMonotone.lean` 的目标是直接证明：

```lean
lemma lin_mono_submultiset (A B : Multiset ℝ)
    (hA : IsInstance A) (hB : IsInstance B) (hAB : A ≤ B) :
    LIN A ≤ LIN B
```

这允许删除任意重数的物品，并允许某个尺寸类型被全部删除。没有假设 A、B 具有相同的类型集合。

## 证明

当 A 为空时，零 LP 解给出 LIN(A)=0，而所有非负权配置 LP 的下确界非负。

当 A 非空时，固定 a∈A。对 B 的每个配置 c，先删去尺寸类型不属于 A 的物品；若这样得到空配置，则改用合法的单件配置 {a}。这个变换有三个性质：

1. 输出始终是 A 的非空合法配置。过滤不会增加非负物品的总大小，而单件 a 小于 1。
2. 对 A 的任何尺寸 t，输出配置的 t 重数至少等于原配置的 t 重数。若过滤结果非空，此重数完全保持；若过滤结果为空，原配置的 t 重数就是零。
3. 使用 `Finsupp.mapDomain` 汇总所有映到同一配置的 LP 权重，总权重恰好保持。

因此 B 的每个可行 LP 解都给出 A 的同成本可行 LP 解。B 中每种保留类型的覆盖至少为其在 B 中的重数，再由 A≤B 保证覆盖足够。取所有 B 可行成本的下确界即得结论。下确界非空性通过单件装箱显式构造，不假设最优实数解一定取得。

源码还给出可复用的 `feasible_mapDomain`、`cover_mapDomain`、`cost_mapDomain`，以及 `feasible_nonempty`、`lin_le_cost`、`lin_zero`、`lin_nonneg`。辅助的装箱转 LP 证明来自同任务已验收 `lin_le_opt` 的独立证明，直接复制其无占位的基础代码，保持本文件只导入定义。

## 一般逐项缩小尚缺什么

题设的 pairs 允许同一个较大尺寸 b 对应多个较小尺寸 a。上面的删除证明不能推出这个一般结论，也不能擅自把 pairs 当作尺寸之间的函数。

一种正确的有限构造如下。设 m(a,b) 为配对重数，n(b) 为 B 中 b 的重数。对配置里每个 b 槽位，独立地以概率 m(a,b)/n(b) 替换成单件 a，剩余概率替换为空；只对确实出现的 b 进行分母运算。由于 pairs 的第二分量是 B 的子多重集，这些概率非负且总和为 1。每个结果配置逐槽缩小，所以容量保持合法。若最终为空，可如上述证明替换成固定 A 单件，这只会增加覆盖且保持 LP 成本。

设原 LP 对 b 的覆盖为 C(b)≥n(b)。则新 LP 对 a 的期望覆盖至少为

`∑ b, C(b) * m(a,b) / n(b) ≥ ∑ b, m(a,b) = A.count a`。

将每个原配置的有限乘积分布乘以其 LP 权重并求和，即得到一般单调性。剩余 Lean 工作是构造这个有限配置分布、证明总质量/期望重数的乘积递推恒等式，以及非零支持的逐槽容量界。`feasible_mapDomain` 本身只处理确定性变换，不能代替随机分流构造。本目录没有把这个尚未形式化的论证声明为已经证明。
