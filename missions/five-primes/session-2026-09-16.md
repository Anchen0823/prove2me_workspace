## 环境备忘

- Bash 每条命令需 `export PATH="/usr/bin:/bin:/c/Windows/System32:/c/Windows:$PATH";`
- `examples/` 不在 lake 构建目标内，无 `.olean`：跨文件 import 需
  `import examples.«five-primes».X`，但 `lake env lean` 单文件检查时缺 olean 会失败。
  → **惯例：把胶水引理合并进同一文件，或写成 `import Mathlib` 自包含模块。**
- `p2m_api.py raw` 输出首行为 HTTP 状态码，解析须 `tail -n +2` 或跳过首行。
- 平台端点：`/theorems?mission_id=<mid>&limit=&offset=`、`/theorems/<id>/graph`、
  `/submissions/<id>`、`/missions/<mid>/milestones`。`/sketches/`、`/theorems/<id>/children`
  均 404。
