## 本轮提出的检验

固定阶数的逼近受分母增长拖累，因此检验让阶数 p 随 n 增长是否有效。取

\[
c_{n,p,k}=\binom nk^2\binom{n+k}k^p/k!,\quad Q_{n,p}=\sum_{k=0}^n c_{n,p,k},
\]
\[
P_{n,p}=-\sum_{k=0}^n c_{n,p,k}
\left(pH_{n+k}+2H_{n-k}-(p+3)H_k\right).
\]

分母来自 Van Assche–Wolfs，arXiv:2404.09799v3，第 5 节。分子来自同节算子迭代：算子将 x^k 乘以 binom(n+k,k)，对 x^k log x 另产生 H_(n+k)-H_k 项。p=2 与平台定义完全一致。p=0 是有限和公式的额外基准参数，不声称论文第 5 节对它作了相同陈述。没有将固定 p 的渐近式直接代入 p=p(n)，因为那需要对 p 一致的误差控制。

## 本次推导并形式化的结果

对全部 n >= 1、整数 p >= 0，

\[
\frac{P_{n,p}}{Q_{n,p}}\le 3H_n-\frac p2.
\]

证明完全初等。对 k <= n，H_(n+k)-H_k 的 n 个项每项至少 1/(2n)，因此和至少 1/2。结合 H_k <= H_n、H_(n-k) >= 0 得到括号至少 p/2-3H_n。权重非负且 k=0 项为 1，因此可以求加权平均。Lean 文件 `Solutions/Sol_EulerGamma_variable_order_obstruction.lean` 证明了完整比值上界，包含分母严格为正的证明。

由此 p >= 6H_n 时 P/Q <= 0，不能逼近 γ > 1/2。若写 P/Q=b/a 为最简分数且 a>0，则此区域 |aγ-b|>1/2，不能贡献任意小的整数线性形式。H_n <= 1+log n 又表明，正值逼近所允许的阶数只能在 O(log n) 尺度内。较小的增长阶数并未被这个定理排除。

本地 Lean v4.33.1、Mathlib 0df444a 检查通过，`#print axioms solution` 只返回 propext、Classical.choice、Quot.sound，无 sorryAx。此结果不依赖任何平台 Open 定理，也不依赖 Γ 函数、鞍点或数值实验。

## 精确有理数实验

遍历 1 <= n <= 256，以及所有整数 0 <= p < ceil(6H_n)，共 8033 个参数对。更大的 p 被上述符号上界排除。每次精确计算 P、Q 并将 P/Q 化为最简分数 b/a。追踪的是 |aγ-b|，而不只是 |γ-b/a|。

γ 使用宽度小于 10^(-191) 的有理区间。构造方式是 H_1024、log 1024=10 log 2，40 项 Euler–Maclaurin 修正和下一项带符号余项界；log 2 使用 2 atanh(1/3) 的 256 项正项级数及几何尾界。所有区间运算使用 Python Fraction。余项界所用数学依据为 NIST DLMF 5.11.2、5.11(ii) 的正实参数误差界，结合 ψ(M)=H_M-γ-1/M；区间构造尚未在 Lean 中形式化。日志中的十进制对数只是浮点显示，不是区间端点。

## 实际结论与剩余工作

本轮没有找到非零整数线性形式趋零的新构造，也没有为 γ 无理性上传依赖猜想的伪证明。变阶方法受到一个严格上界限制；未被限制排除的有限样本仍明显受到本原分母增长阻碍。这不证明整个变阶方法不可能成功，更不证明 γ 有理。

若继续此方向，有意义的问题是为 0 <= p < 6H_n 的增长阶数建立一致渐近和本原分母的统一下界/异常约分机制，而不是继续扩大位数。另一方向是更换构造以产生可证明的分母消去；在此之前，不把“已验证有限范围的非零”升级为无限子序列定理。

本轮提交的是独立的方法限制定理，不会用它人为建立主目标的证明依赖，也不声称它使主目标接近自动完成。
